# Hospital Management System

A console-based hospital management system built using Java.

## Features
-> Add patients
-> View the list of patients
-> View available doctors
-> Book appointments using Patient ID and Doctor ID
-> View booked appointments
-> Exit the system

## Concepts Used
-> Java Classes and Objects
-> Constructors
-> ArrayLists
-> Object relationships
-> Loops
-> Switch statements
-> Conditional statements
-> Scanner for user input

## Project Structure
- `Main.java` : Contains the main menu and program flow
- `Patient.java` : Stores patient information
- `Doctor.java` : Stores doctor information
- `Appointment.java` : Connects a patient with a doctor and appointment details

## Future Improvements
Possible future improvements include:

-> Appointment cancellation
